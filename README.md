# 论文速览 PaperBrief

2026 软工实践周参赛作品 · 高级组 · 科研与知识挖掘

把一段论文摘要粘进来，自动划出重点句子和关键词。纯前端，没有后端，也没有调用外部接口。

## 功能

- 粘贴中英文摘要，生成 3 句要点
- 提取高频词作为关键词
- 显示字数、句数和处理耗时
- 支持 `Ctrl + Enter` 快捷生成

## 怎么打开

方法一：直接双击 `index.html`。

方法二（推荐，`file://` 下个别 API 会有限制）：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 算法说明

不是大模型，就是一个很朴素的抽取式摘要：

1. 按 `。！？.!?` 分句；
2. 统计词频，中文按两个字切分（没有分词库）；
3. 每句得分 = 句中不重复词的词频之和 ÷ 句子长度平方根；
4. 取分数最高的 3 句，再按原文顺序排回去。

关键词就是词频最高的 8 个词。
